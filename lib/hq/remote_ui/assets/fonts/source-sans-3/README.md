# Source Sans 3 web fonts

Tycho self-hosts the variable upright and italic WOFF2 files from Adobe's Source Sans repository. The Remote UI uses the full weight range and keeps the existing system sans-serif stack as its fallback. Code and preformatted content continue to use Tycho's monospace stack.
