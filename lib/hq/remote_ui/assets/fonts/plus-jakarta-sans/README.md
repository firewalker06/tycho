# Plus Jakarta Sans web fonts

Tycho self-hosts the Latin variable normal and italic WOFF2 files for Plus Jakarta Sans. The Remote UI supports weights 200 through 800 and keeps the system sans-serif stack as its fallback. Code and preformatted content continue to use Tycho's monospace stack.

- Fontsource package: `@fontsource-variable/plus-jakarta-sans 5.3.0`
- Font version: `v12`
- Fontsource page: https://fontsource.org/fonts/plus-jakarta-sans/about
- Exact Fontsource source commit: https://github.com/fontsource/font-files/commit/02b28c06b126c852a5b966b44aef777ca923f6f6
- Fontsource source paths: `fonts/variable/plus-jakarta-sans/files/plus-jakarta-sans-latin-wght-normal.woff2` and `fonts/variable/plus-jakarta-sans/files/plus-jakarta-sans-latin-wght-italic.woff2`
- Upstream project: https://github.com/tokotype/PlusJakartaSans
- Upstream license: https://github.com/tokotype/PlusJakartaSans/blob/master/OFL.txt
- License: SIL Open Font License 1.1, retained in `LICENSE.md`
- Runtime dependencies: none; Tycho serves both files from its packaged Remote UI assets
