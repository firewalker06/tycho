# Bundled theme photos

These optimized product assets ship with the application and require no external
network request. See [credits](CREDITS.txt) and [provenance](provenance.json) for
creators, source URLs, location evidence, transformations, hashes, and generation
prompts. Full licenses: [CC BY 3.0](CC-BY-3.0.txt) and
[CC BY-SA 4.0](CC-BY-SA-4.0.txt). The adapted Depok image remains CC BY-SA 4.0;
the separate application code remains under its own license.

- Senggigi Beach: Midori's own-work S4 view from Jalan Raya Senggigi.
- Depok City: RasyaAbhirama13's own-work D4 photograph of Margo City in Depok.
  Original daylight colors are retained; this is not a night photograph.
- Waking Up and Cyberspace: fictional generated artwork from one built-in
  image_gen call per asset, inspected before WebP conversion. No CLI/API
  fallback or unrelated stock image was used. Exact model revision is not
  exposed by the built-in tool. Original PNGs remain at the tool's default
  generated-image destination; production uses the bundled WebP copies.

Image options use 20% strength, 50% edge vignette and centered focal position by default. Explicit saved settings remain unchanged. Vignette fades image edges toward the palette background; no CSS blur or center wash is applied. Original images remain unchanged. The old Cyberpunk asset and its separate provenance remain packaged for compatibility; the visible theme is Cyberspace with generated space-station artwork.

The operator selected Senggigi S4 and Depok D4. Current assets are resized from their full-resolution originals without baked visual treatments. Earlier files and their attribution records remain under legacy/. Cyberspace now uses operator-approved R3. Its generated edit prompt and input/output hashes are recorded in provenance.json. The rejected first station is replaced; no treatment is baked in during integration.
