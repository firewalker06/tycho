# Tycho v0.12.1

## Rollout improvements

- **Fresh Summary views.** An open Summary now notices newer Conversation
  activity, polls for updates without replacing the focused workspace, and
  offers the newest fetched Summary in place. The behavior is covered on
  desktop and mobile.
- **One view of active QueueWork.** Entries in the batch currently being
  processed no longer appear again in the pending queue. The durable batch and
  **Read queue** Conversation record remain intact, and unresolved entries
  return when processing stops or fails.
- **Larger attachments.** Individual managed-agent uploads and workspace image
  previews can now be up to 20 MB. The five-file and 25 MB aggregate message
  limits are unchanged.

## Fixes

- Compact Claude image tool results to a media label before projecting them
  into conversation and memory content, avoiding megabytes of duplicated
  base64 data. The unchanged raw stream still retains the original payload for
  evidence and recovery.
- Keep the runner-published harness exit status authoritative during
  finalization. A later TERM-to-KILL escalation of the wrapper can no longer
  replace the actual harness status.

## Compatibility and upgrade notes

- No manual migration is required for projects, schedules, managed agents,
  delegation, QueueWork, credentials, or memory.
- Existing oversized memory journals can be backed up and rebuilt from their
  raw logs if needed; new Claude image results are compacted automatically.
- v0.11.0 remains the final Intel macOS bottle. v0.12.1 publishes Apple Silicon
  macOS and Linux bottles; Intel users can continue running from source.

## Rollback

Before publication, close the release-preparation pull request or revert its
version-and-documentation commit. After publication, do not move the public
tag: cut a corrected patch release for a harmless issue, or mark the GitHub
release as a prerelease/delete its release page for a severe issue and then
publish a corrected patch.
