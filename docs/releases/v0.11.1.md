# Tycho v0.11.1

## Highlights

- Add server-aware CLI controls. Use `--server SERVER_KEY` for supported
  configured-peer restart, update, doctor, metrics, project, agent, and
  schedule commands; JSON output and error contracts stay machine-readable.
- Persist Tycho-managed identity in agent system context and the Remote UI so
  managed sessions retain their trusted server, agent, and delegation context.
- Archive protected delegation callback history with its provenance when a
  parent is archived, rather than leaving callback-only queues behind.
- Settings can update a configured Remote server from its overflow menu when
  that peer reports a Homebrew Tycho installation.
- The confirmation names the restart behavior. Tycho waits for the peer to
  return, refreshes its resource catalog, and restores ordinary polling after
  a failure.

## Fixes and maintenance

- Fix Project Browser scrolling so focused workspace content stays reachable.
- Remove the redundant delegated-agent list from the Remote UI.
- Remove obsolete planning, protocol-research, and stale capture documentation
  and assets that no longer describe supported behavior.

## Compatibility

- No configuration or data migration is required.
- Source-installed, offline, and older peers do not expose an Update action.
  Update source checkouts with Git and `bin/setup` instead.
- The Remote UI update route accepts configured peers only. Ad-hoc
  `loopback-PORT` aliases retain their existing resource proxy behavior but
  cannot trigger an update.
- Intel macOS Homebrew support remains deprecated but updateable during the
  existing migration period.
