# Tycho v0.11.1

## Highlights

- Settings can update a configured Remote server from its overflow menu when
  that peer reports a Homebrew Tycho installation.
- The confirmation names the restart behavior. Tycho waits for the peer to
  return, refreshes its resource catalog, and restores ordinary polling after
  a failure.

## Compatibility

- No configuration or data migration is required.
- Source-installed, offline, and older peers do not expose an Update action.
  Update source checkouts with Git and `bin/setup` instead.
- Intel macOS Homebrew support remains deprecated but updateable during the
  existing migration period.
