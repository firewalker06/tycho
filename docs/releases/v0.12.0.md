# Tycho v0.12.0

## Highlights

- **Durable QueueWork processing.** Tycho claims pending user prompts and
  delegated reports into one receiver-owned FIFO batch, preserves attachments
  and provenance, and renders one compact, right-aligned **Read queue** block.
  Expand it to inspect canonical IDs, sources, targets, and outcomes.
- **Fewer queue turns.** Due queued work joins an inquiry answer or ordinary
  prompt in the same native run. Successful batches clear automatically;
  unsuccessful or input-required runs retain unresolved entries, and work that
  arrives after the claim stays in the next batch.
- **Safer autonomous continuation.** Agents can enqueue delayed work, while a
  sleep circuit breaker detects repeated blocking waits and schedules bounded
  recovery instead of leaving a run open.
- **Stronger state recovery.** Rolling snapshots, transactional restore, and
  session-ID reconciliation protect managed agents from truncated files,
  accidental bulk removal, and stale process writes.
- **Smaller maintained product.** The retired experimental assistant surface,
  runtime, schemas, actions, assets, and fixtures are removed; legacy records
  remain hidden.

## Remote UI and workflow improvements

- Page older Conversation blocks on demand so large transcripts no longer
  create an oversized initial response or DOM, especially in iOS PWAs.
- Submit inquiries optimistically with safe rollback, prioritize quick agents
  waiting for a response, restore Settings primary navigation, and expose
  schedule-session archive controls.
- Preserve exact JSON attachment bytes, allow all pull-request diff comment
  sections, and fix File Browser image limits and row alignment.
- Add harness authentication snapshots and current Claude Opus 5.5 and Fable
  5.1 model suggestions.

## Compatibility and upgrade notes

- No manual migration is required for projects, schedules, managed agents,
  delegation, QueueWork, credentials, or memory.
- Removed experimental configuration is ignored. Legacy agent records remain
  hidden and can be left in place.
- Update every Tycho-owned skill from **Settings → Skills** after upgrading so
  agents receive the current QueueWork contract and CLI guidance.
- v0.11.0 remains the final Intel macOS bottle. v0.12.0 publishes Apple Silicon
  macOS and Linux bottles; Intel users can continue running from source.

## Maintainer and CI change

Tycho no longer runs hosted CI for pull requests. The protected merge gate now
requires `signoff/tycho-bin-test` on the exact pushed commit after a trusted
maintainer runs the complete local `bin/test` suite. This release was prepared
and attested through that workflow.

## Rollback

Before publication, close the release-preparation pull request or revert its
version-and-documentation commit. After publication, do not move the public
tag: fix a harmless problem in v0.12.1, or mark the GitHub release as a
prerelease/delete its release page for a severe issue and cut a corrected patch
from `main`.
